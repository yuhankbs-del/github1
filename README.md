# 법인카드 집근처 사용 분석

법인카드 사용내역 엑셀을 올리면 카카오지도로 집 근처 사용을 분석하고, 규칙 기반 이상징후 탐지와 Gemini 기반 경영진 보고서를 만들어 주는 웹페이지입니다.

- 사용내역 파일은 브라우저 안에서만 처리되며 서버에 저장되지 않습니다.
- 카카오 JavaScript 키, Gemini API 키는 화면에서 입력하며 사용자 브라우저에만 저장됩니다.
- 카카오 developers 앱의 Web 플랫폼 사이트 도메인에 이 페이지 주소(예: `https://yuhankbs-del.github.io`)를 등록해야 지도가 표시됩니다.
