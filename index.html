카카오 지도 JavaScript 키

  1. 카카오 developers → 내 애플리케이션 → 앱 생성
  2. 앱 설정 → 플랫폼 → Web → 사이트 도메인에 등록
  3. 제품 설정 → 카카오맵 → 사용 설정 ON
  4. 앱 키 → JavaScript 키를 아래에 붙여넣기
키는 이 브라우저(localStorage)에만 저장됩니다.
